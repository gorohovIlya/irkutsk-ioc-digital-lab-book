## Актуальность и решаемые задачи
1. **Стандартизация:** Внедрение единого строгого формата ведения лабораторных журналов и протоколов химических экспериментов.
2. **Удобство для практикантов:** Снижение порога входа и упрощение документирования опытов для студентов-практикантов.
3. **Гибридная работа (Offline-First):** Возможность продолжать работу с записями на домашнем ПК или в лаборатории без доступа к сети с последующей безопасной синхронизацией с центральным сервером института.

---

## Технологический стек

### Клиентская часть (Frontend & Desktop)
* **Framework:** Angular (TypeScript)
* **Desktop-оболочка:** Tauri (Rust + WebView2) — легковесный нативный клиент, оптимизированный для работы под Windows и Linux.
* **Локальное хранилище:** SQLite (через `@tauri-apps/plugin-sql`) для работы в автономном режиме.

### Серверная часть (Backend)
* **API Framework:** Python 3.12+ / FastAPI
* **База данных:** PostgreSQL
* **Reverse Proxy:** Nginx

### Инфраструктура и безопасность
* **Контейнеризация:** Rootless Podman (для изоляции и безопасности в production-среде) / Docker Compose (для локальной разработки).
* **Безопасность:** Строгая валидация данных (Pydantic), отсутствие привилегированных контейнеров (rootless), закрытый сетевой контур БД внутри локальной сети института.

## Архитектура и сценарии применения

Система спроектирована по принципу **Local-First** и поддерживает два режима работы:

```text
┌─────────────────────────────────────────────────────────────┐
│             Рабочая станция / Домашний ПК                   │
│  ┌───────────────────────────────────────────────────────┐  │
│  │           Клиентское приложение (Angular + Tauri)     │  │
│  │   [ Локальная БД: SQLite ] ◄──► [ Модуль синхронизации]│  │
│  └───────────────────────────────────────────────────────┘  │
└──────────────────────────────┬──────────────────────────────┘
                               │ HTTPS / REST API (при наличии сети)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│             Локальный сервер института (Linux)              │
│  ┌─────────────┐     ┌─────────────┐     ┌───────────────┐  │
│  │    Nginx    │ ──► │   FastAPI   │ ──► │  PostgreSQL   │  │
│  └─────────────┘     └─────────────┘     └───────────────┘  │
│                 (Изолировано в Rootless Podman)             │
└─────────────────────────────────────────────────────────────┘
```

1. **Работа в локальной сети института:** На выделенном сервере развернут контур из Nginx, FastAPI и PostgreSQL. Клиенты (рабочие станции в лабораториях) подключаются к нему по локальной сети.
2. **Автономный режим (Offline):** При обрыве связи или при работе с домашнего ПК приложение автоматически переключается на встроенную базу данных **SQLite**. При восстановлении соединения накопленные изменения синхронизируются с сервером.
3. **Перенос данных (Экспорт / Импорт):** Реализована возможность безопасной выгрузки зашифрованного пакета данных (настройки профиля, дампы выбранных экспериментов) для переноса на домашний компьютер и обратно.

## Быстрый старт (для разработчиков)

### Требования к окружению
* **Python** 3.12+ и менеджер пакетов **uv**
* **Node.js** 20+ (LTS) и Angular CLI
* **Rust / Cargo** (для сборки Tauri)
* **Podman** или **Docker** (для запуска БД при разработке)

### 1. Запуск серверной части (Backend)
```bash
cd backend
cp .env.example .env              # Настройте параметры подключения к БД
uv sync                           # Автоматически создаст .venv и установит все зависимости из uv.lock
uv run uvicorn app.main:app --reload
```
*Документация API (Swagger) будет доступна по адресу: `http://localhost:8000/docs`*


### 2. Запуск клиентской части (Frontend / Tauri)
```bash
cd frontend
npm install

# Запуск только веб-интерфейса в браузере:
ng serve

# Запуск в режиме десктопного приложения Tauri:
npm run tauri dev
```
