# Техническое задание

Требуется реализовать приложение "Электронный лабораторный журнал" для ИрИХ СО РАН. Приложение развёртывается в локальной сети института. В качестве веб сервера - один из местных компьютеров. Должна поддерживаться возможность работы с журналом на домашнем компьютере пользователя в клиентском приложении. Для этого необходимо, чтобы у пользователя была возможность выгрузить данные из своего профиля в виде архива. Для того, чтобы разархивировать данные система должна запросить пароль. После работы в клиентском приложении пользователь также может выгрузить данные для последующей загрузки на сервер. В таком случае при загрузке на сервер пользователю нужно предложить сравнение существующих данных и измененных, чтобы он сам выбрал, какие изменения оставить, а какие - отклонить (аналог **git diff**).

## Функционал

1. Два варианта работы с приложением:
    - Через браузер. Данные сохраняются в БД на сервере (PostgreSQL)
    - Через Desktop-интерфейс (Tauri). Данные сохраняются в локальную базу данных (SQLite)
2. Просмотр пользователем информации о себе
3. Создание и редактирование экспериментов
4. Возможность нескольким пользователям работать над одним эксперииментом
5. Импорт данных из файлов (Excel, Origin, ...)
6. Выгрузка данных в защищённый архив
7. Сравнение данных, загруженных из архива с текущим состоянием

## Интерфейс (Обычный пользователь)

1. Главная страница:
    - Ссылка на сайт института
    - Страница входа вличный кабинет
2. Регистрация и авторизация:
    - Данные для регистрации: **Пароль, Электронная почта, Должность, Подразделение, ФИО**
    - Данные для авторизации: **Пароль, Электронная почта**
3. Страница личного кабинета:
    - Информация о пользователе
    - Список подразделелений
    - Список экспериментов
4. Страница эксперимента
    - Краткие сведения об эксперименте
    - Таблица **Веществ**. Параметры вещества: **Название, CAS-номер, молярная масса, количество, масса, плотность, объём**
    - Кнопка "Назад"
    - Кнопка "Редактировать"

## Интерфейс (Руководство)
1. Главная страница:
    - Ссылка на сайт института
    - Страница входа вличный кабинет
2. Регистрация и авторизация:
    - Данные для регистрации: **Пароль, Электронная почта, Должность, Подразделение, ФИО**
    - Данные для авторизации: **Пароль, Электронная почта**
    - Ответ на контрольный вопрос
3. Страница личного кабинета:
  - Список подразделений
4. Страница подразделения:
  - Список экспериментов, проводимых в подразделении
  - Статистика по экспериментам
